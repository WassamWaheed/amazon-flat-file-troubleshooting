# Amazon Flat File Troubleshooting

A practical reference for diagnosing Amazon bulk upload and flat-file problems.

## Included Files
- [Flat File Troubleshooting Checklist](flat_file_checklist.md)
- [Processing Report Log Template](processing_report_log.csv)

## Troubleshooting Workflow
1. Save the original upload and processing report.
2. Identify affected SKUs and error codes.
3. Separate template/formatting problems from catalog-data problems.
4. Validate product type, identifiers, required attributes, and variation fields.
5. Correct the source workbook rather than patching only the live listing.
6. Test with a small controlled upload.
7. Review the new processing report.
8. Verify the live catalog after processing.

## Common Areas to Review
- Product type
- Brand and identifiers
- Required attributes
- Parent/child relationships
- Variation theme
- Allowed values
- Image references
- Existing catalog conflicts

## Privacy
Never publish client flat files, account identifiers, credentials, or confidential product exports in a public portfolio.
