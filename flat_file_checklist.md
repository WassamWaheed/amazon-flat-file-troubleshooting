# Amazon Flat File Troubleshooting Checklist

## Before Upload
- [ ] Correct template/product type selected
- [ ] Required fields are populated
- [ ] SKUs are unique
- [ ] Parent/child fields are consistent
- [ ] Variation theme is valid
- [ ] Identifiers and brand values are reviewed
- [ ] Allowed-value fields use valid entries

## After Upload
- [ ] Processing report downloaded
- [ ] Errors grouped by root cause
- [ ] Failed SKUs isolated
- [ ] Source workbook corrected
- [ ] Small test batch re-uploaded
- [ ] Live catalog verified after processing
